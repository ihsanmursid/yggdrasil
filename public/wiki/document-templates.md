# Document templates

Finance nav templates for generated documents (offer letters and similar). Not certificate templates.

See also:

- [offer-admission.md](offer-admission.md)
- [certificates.md](certificates.md)
- [finance.md](finance.md)
- [certificates-admin.md](certificates-admin.md)

## Admin routes

Finance nav item name Template: `/document-templates`, `/document-templates/add`, `/document-templates/:masterDocumentTemplateId`, `/document-templates/:masterDocumentTemplateId/edit`.

Certificate templates are a different nav under Report → Certificates (`/certificate-templates`). See [certificates-admin.md](certificates-admin.md).

## Modules

Modules: master-document-template.

API: `/v1/masterDocumentTemplates`. Offer-admission preview uses `/v1/offerAdmissions/previewPdf`. See [offer-admission.md](offer-admission.md).

Portal: admin.
